# Statistical Data Analysis with R

English course materials accompanying three sessions on population and sample, uncertainty and estimation, and maximum likelihood and efficiency.

## Read the book

The rendered book is in `docs/index.html`. GitHub Pages should publish the `docs` directory from the main branch.

## Edit and render

Edit the four `.qmd` files with RStudio. Install Quarto and R, with the packages `knitr`, `rmarkdown`, `HistData`, `ggplot2`, and `tidyverse`.

From the project directory run:

```
quarto preview
quarto render
```

Commit both updated source files and the rendered `docs` folder. Updates pushed to the configured publishing branch are deployed by GitHub Pages.

The interactive quizzes run in the browser and do not submit answers.
